# List Report Page

The list report page enables users to filter, view, and manage large sets of business objects in SAP Fiori elements for OData V4. It serves as an entry point for navigating to detailed item information on object pages.

The list report page combines powerful functions for filtering large lists with different ways of displaying the resulting item list. It is often used as an entry point for navigating to the item details, which are usually shown on an object page. For more information about the object page, see [Object Page](object-page-645e27a.md).

## Main Features

The list report page view includes the following main features:

-   **Shell bar** that displays the application title and the user menu icon.

    For more information, see [Configuring the Application Title](configuring-the-application-title-ac70343.md).

-   **Variant management** that lets users save and switch personalized filter, sort, and column settings as reusable view variants.

    For more information, see [Managing Variants](managing-variants-8ce658e.md).

-   **Header toolbar** with a generic *Share* menu that lets users share the content of the page using tools such as email or Microsoft Teams.

    For more information, see [The Share Functionality](the-share-functionality-022bf0d.md).

-   **Filter bar** that offers additional features such as mandatory filters or default filter values.

    For more information, see [Configuring Filter Bars](configuring-filter-bars-4bd7590.md).

-   **Content area** that includes a table, a chart, or both. You can configure it for optimal display of data.

    For information about using tables and charts in the content area, see [Multiple Views on the List Report Page](multiple-views-on-the-list-report-page-a37df40.md).

    For more information, see [Table Types](table-types-c0f6592.md) and [Configuring Charts](configuring-charts-653ed0f.md).


For more information about the list report page, see the [SAP Design System guidelines](https://www.sap.com/design-system/fiori-design-web/page-types/floorplans/list-report-floorplan-sap-fiori-element).

For more information and live examples, see the SAP Fiori development portal at [Standard Floorplans - List Report Page](https://ui5.sap.com/test-resources/sap/fe/core/fpmExplorer/index.html#/topic/floorplanListReport/simpleListReport).
