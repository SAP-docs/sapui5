# Creating New Business Objects

Create mode options for adding new business objects in SAP Fiori elements for OData V4 include inline creation, create page, dialog, and an external app. Use these options to enable flexible object creation workflows that match your application requirements.

Create mode is available as follows:

-   `Inline` and `InlineCreationRows`: the user can create new business objects without any navigation. For more information, see [Enabling Inline Creation Mode or Empty Row Mode for Table Entries](enabling-inline-creation-mode-or-empty-row-mode-for-table-entries-cfb04f0.md).

-   Create page: the application navigates to an object page where the user can enter values and create a new object. This is the default mode if navigation from the table is available.

-   Create dialog: a dialog opens where the user can enter values and trigger object creation. For more information, see [Enabling Object Creation Using the Dialog on the List Report Page](enabling-object-creation-using-the-dialog-on-the-list-report-page-ceb9284.md) and [Enabling Object Creation Using the Dialog on the Object Page](enabling-object-creation-using-the-dialog-on-the-object-page-7fee938.md).

-   `External`: clicking the *Create* button triggers navigation to an external SAP Fiori launchpad-based application which manages object creation. For more information, see [Create Mode as an External App](create-mode-as-an-external-app-5c2bc2e.md).


For more information about creating new business objects in tables, see [Data Entry and Editing](data-entry-and-editing-b97dd5d.md).
